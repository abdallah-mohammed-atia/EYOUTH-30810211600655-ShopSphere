Cloud service classification

- Frontend hosting: Vercel — PaaS. Reason: Vercel provides platform services to build and host static and serverless frontend code without managing underlying infrastructure.
- Backend hosting: Vercel Serverless Functions — PaaS. Reason: Serverless functions are platform-managed compute where scaling and runtime are provided by the platform.
- Production database: Supabase (Postgres) — SaaS. Reason: Supabase provides a managed Postgres database as a service with hosted backups and supervised access.
